## 2. Executive Summary & Justification
*   **Business Objective:** Apply NAC to protect access ports that will serve as the entry point into the network.
*   **Risk Profile:** High 
*   **Scope:** Access Ports on Switches.
*   **Estimated Downtime:** Zero downtime.

## 3. Pre-Implementation Validation (Pre-Checks)
*Execute these commands prior to the maintenance window to establish a baseline.*

1. Ensure Active Directory is up to date with every user

2. Ensure that Cisco ISE is synced with Active Directory 

3. Document which ports will serve as the access port that will utilize 802.1X

4. Check to see if Access Switch is already using AAA or local authentication.

## 4. Implementation Steps

1. Log in to Access Switches

2. Configure AAA Security:

```config
aaa new-model
aaa authentication dot1x default group radius
aaa authorization network default group radius
```

3. Configure 802.1X: 

```config
authentication host-mode multi-domain
authentication order dot1x
authentication priority dot1x
authentication port-control auto
authentication periodic
```

4. (IF end device is not a PC such as IP Phone or AP) Configure 802.1X MAB:

```config
authentication host-mode multi-domain
authentication order mab dot1x
authentication priority mab dot1x
authentication port-control auto
authentication periodic
```
5. Configure RADIUS Server (ISE) 

```config
radius server ISE
 address ipv4 192.168.122.2 auth-port 1812 acct-port 1813
 key Pateau1!
```
## 5. Post-Implementation Validation (Post-Checks)
*Execute these commands immediately after implementation to verify success.*

```bash
show run | section aaa
show run | section radius
```
*Run Testing with failed and successful credentials*

```bash
show authentication sessions
show authentication sessions g1/0/2 details
show vlan brief (ensure dynamic vlan assignments)
show mac-address (vlan assignment verifcation) 
```

## 6. Rollback / Backout Plan
*Steps required to restore the network to its original state if the migration fails.*

### Step 1: Revert AAA and RADIUS
*This one command will remove EVERY 802.1X configuration including RADIUS Server Config*

```config
no aaa new-model
[confirm] enter
```
### Step 2: Revert 802.1X Port 

```config
no authentication host-mode multi-domain
no authentication order mab dot1x
no authentication priority mab dot1x
no authentication port-control auto
no authentication periodic
```
